# Dashboard Executivo DATATRAN 2025
## Sobre o projeto

Este projeto apresenta uma análise executiva dos acidentes registrados em rodovias federais brasileiras ao longo de 2025, a partir dos dados públicos do **DATATRAN / Polícia Rodoviária Federal**.

O dashboard foi desenvolvido para transformar uma base extensa de ocorrências em uma visão clara sobre **volume, gravidade, localização, causas, tipos de acidente e impacto social estimado**.
A proposta é ir além da visualização dos números e destacar os pontos que merecem maior atenção.

## O que o dashboard permite analisar

O painel reúne indicadores e visualizações sobre:

- evolução dos acidentes ao longo do ano;
- acidentes, mortes, feridos e feridos graves;
- acidentes com vítimas fatais;
- mortes a cada 100 acidentes;
- distribuição por gravidade;
- estados com maior concentração de ocorrências;
- relação entre volume de acidentes e letalidade;
- principais causas;
- tipos de acidente;
- dias e horários com maior concentração;
- condições meteorológicas;
- tipo de pista;
- uso do solo;
- municípios e rodovias com maior impacto;
- frequência x gravidade;
- prioridades de atuação com base nos dados.

## Filtros disponíveis

As análises podem ser filtradas por:

- período;
- UF;
- município;
- BR;
- classificação do acidente;
- causa;
- tipo de acidente;
- condição meteorológica.

Todos os indicadores, gráficos, rankings e interpretações são atualizados conforme o recorte selecionado.

## Inteligência aplicada à análise

Além dos gráficos, o dashboard apresenta interpretações curtas em linguagem natural para destacar o que cada resultado representa.

O bloco **“Onde agir agora”** identifica os principais pontos de atenção a partir do recorte analisado, considerando volume, gravidade e exposição econômica estimada.

## Impacto social estimado

Os valores financeiros apresentados no dashboard são **estimativas de custo social dos acidentes**.

O DATATRAN não informa o custo financeiro individual de cada ocorrência. Por isso, a estimativa utiliza custos médios por gravidade publicados pelo **Ipea**, atualizados para valores de 2025.

Esses custos podem incluir impactos como:

- perda de produção;
- atendimento às vítimas;
- danos materiais;
- custos institucionais.

Os valores apresentados **não representam despesas diretamente registradas no DATATRAN nem economia garantida**. São estimativas usadas para apoiar comparação e priorização.

## Limitações da análise

Os dados permitem identificar padrões, concentrações e associações, mas não permitem concluir causalidade de forma isolada.

Alguns cuidados de interpretação:

- maior número de acidentes não significa necessariamente maior risco relativo;
- maior letalidade não identifica, por si só, a causa do problema;
- a base não considera diretamente o volume de veículos que circula em cada trecho;
- fatores externos não registrados podem influenciar os resultados;
- os valores financeiros são estimativas de impacto social.

Por isso, os resultados devem ser utilizados como apoio à investigação e à priorização de ações.
